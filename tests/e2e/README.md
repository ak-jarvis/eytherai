# E2E Tests

Playwright no-patient-data journeys for the Phase 1 synthetic local app.

Current coverage includes invite login/logout, setup readiness, no-PII test-email acknowledgement, worklist, Active Send blocking, manual match, owner summary, finance export, and audit trail checks.

These tests remain synthetic-only. They do not use real patient records, raw claim documents, raw email bodies, raw MIME, mailbox screenshots, credentials, OAuth tokens, or identifiable fixtures.
